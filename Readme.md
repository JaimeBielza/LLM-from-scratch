# LLM From Scratch

Estoy construyendo un modelo de lenguaje desde cero para entender de verdad
cómo funcionan por dentro. Este repo es el registro público de ese proceso:
el código que voy escribiendo y las notas que voy tomando a medida que avanzo.


## Qué estoy siguiendo

- **[Stanford CS336 — Language Modeling from Scratch](https://cs336.stanford.edu/)**
  (Percy Liang, Tatsunori Hashimoto). Sigo el curso por libre con el material
  que han hecho público (vídeos, código y assignments).
- **[Build a Large Language Model (From Scratch)](https://sebastianraschka.com/llms-from-scratch/)**,
  de Sebastian Raschka. Lo uso como material de estudio profundo y guia sobre el codigo. 


Este proyecto no está afiliado ni respaldado por Stanford ni por Sebastian
Raschka; simplemente sigo su material público. 

El uso de la agentes de codificación basados en IA, solamente los estoy usando cómo tutor/profesor no como creador de codigo. 
No tendria sentido.
